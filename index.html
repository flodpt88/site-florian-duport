Vos questions, mes réponses.

C'est quoi, une landing page ?

Une page unique, pensée pour une seule action : vous appeler, réserver ou vous écrire. Tout ce qu'un client doit savoir tient sur un seul écran qui défile.

Que comprennent les 200 € ?

Le design sur mesure, vos textes retravaillés, les images, la version téléphone, le formulaire de contact, le référencement de base et la mise en ligne.

Combien de temps faut-il ?

3 jours une fois que j'ai vos informations (textes, photos, coordonnées). La date de mise en ligne est fixée dès le départ.

Le nom de domaine est-il compris ?

Oui. Le nom de domaine (l'adresse de votre site, par exemple votre-boulangerie.fr) est inclus dans les 200 €, et je m'occupe de tout le paramétrage.

À quoi sert le suivi à 20 € par mois ?

Les modifications sont illimitées : horaires, tarifs, photos, textes, je les fais pour vous. Seule une refonte complète du site n'est pas comprise. Il est sans engagement : vous arrêtez quand vous voulez.

Comment se passe le paiement ?

Un acompte au lancement du projet, puis le solde à la mise en ligne. Vous payez la fin quand votre page est prête.

Je n'ai ni photos ni textes, c'est un problème ?

Non. On en parle au démarrage, j'écris les textes avec vous et je prépare les images.

Mon site sera-t-il visible sur Google ?

Le référencement de base est inclus : titres, descriptions, vitesse, version téléphone. Personne ne peut honnêtement promettre la première place, mais votre page part avec toutes ses chances.
